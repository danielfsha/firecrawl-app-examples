# Logo

An interactive logo component with a context menu for brand actions. Right-click or long-press to reveal menu options.

<Preview code={`import { Logo, LogoMenuItem, LogoMenuSeparator } from "@/components/ui/Logo";

<Logo>
  <LogoMenuItem onClick={() => window.open("https://firecrawl.dev", "_blank")}>
    Open in new tab
  </LogoMenuItem>
  <LogoMenuSeparator />
  <LogoMenuItem onClick={() => navigator.clipboard.writeText("svg content")}>
    Copy logo as SVG
  </LogoMenuItem>
  <LogoMenuItem>
    Download brand assets
  </LogoMenuItem>
  <LogoMenuSeparator />
  <LogoMenuItem onClick={() => window.open("https://firecrawl.dev/brand", "_blank")}>
    Visit brand guidelines
  </LogoMenuItem>
</Logo>`}>
  <Logo>
    <LogoMenuItem onClick={() => window.open("https://firecrawl.dev", "_blank")}>
      Open in new tab
    </LogoMenuItem>
    <LogoMenuSeparator />
    <LogoMenuItem onClick={() => navigator.clipboard.writeText("firecrawl")}>
      Copy logo as SVG
    </LogoMenuItem>
    <LogoMenuItem>
      Download brand assets
    </LogoMenuItem>
    <LogoMenuSeparator />
    <LogoMenuItem onClick={() => window.open("https://firecrawl.dev/brand", "_blank")}>
      Visit brand guidelines
    </LogoMenuItem>
  </Logo>
</Preview>

## Features

- Right-click or long-press to open the context menu
- Animated hover effect on menu items with spring physics
- Text turns primary color on hover
- Click outside to dismiss

## Composition

```

├── LogoMenuItem
├── LogoMenuSeparator
└── LogoMenuItem
```

## API Reference

### Logo
