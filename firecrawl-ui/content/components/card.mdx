## API Reference

### Card

The root container for card content.

| Prop | Type | Default |
|------|------|---------|
| `size` | `"default" \| "sm"` | `"default"` |
| `className` | `string` | — |

### CardHeader

Container for title, description, and optional action.

| Prop | Type | Default |
|------|------|---------|
| `className` | `string` | — |

### CardTitle

The card title text.

### CardDescription

Helper text under the title.

### CardAction

Content placed in the top-right of the header (buttons, badges, etc).

### CardContent

Main card body.

| Prop | Type | Default |
|------|------|---------|
| `className` | `string` | — |

### CardFooter

Actions and secondary content at the bottom.

| Prop | Type | Default |
|------|------|---------|
| `className` | `string` | — |
