# Button

A versatile button component built on top of Base UI with multiple variants and sizes.

## Preview

<preview>button</preview>

## Usage

```tsx
import { Button } from "@/components/ui/button";

<Button variant="default">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>
```

## Variants

- `default` — Primary orange button
- `secondary` — Subtle gray background
- `outline` — Bordered with transparent fill
- `ghost` — No background until hovered
- `destructive` — Red for dangerous actions
- `link` — Styled as an underlined link

## Sizes

- `xs` — Extra small
- `sm` — Small
- `default` — Standard
- `lg` — Large
- `icon` — Square icon button
