## API Reference

### Tabs

Root container that manages tab state.

| Prop | Type | Default |
|------|------|---------|
| `defaultValue` | `string` | — |
| `onValueChange` | `(value: string) => void` | — |
| `className` | `string` | — |

### TabsList

Container for tab triggers. Renders the pill-shaped background.

### TabsTrigger

Individual tab button. Supports icons as children alongside text.

| Prop | Type | Default |
|------|------|---------|
| `value` | `string` (required) | — |
| `className` | `string` | — |

### TabsDivider

A thin vertical separator rendered between triggers.
